# Identidade de conversão — Liberte-se

Aplicar somente ao projeto ou à marca Liberte-se.

| Função | Cor | Código |
|---|---|---|
| Principal | Verde profundo | `#074F3B` |
| Secundária | Vermelho escuro | `#901517` |
| Apoio | Terracota | `#BA4A50` |
| Destaque suave | Rosa queimado | `#D9697E` |
| Texto principal | Verde quase preto | `#05100C` |
| CTA principal | Dourado terroso | `#C88D49` |
| Fundo principal | Creme | `#FAF5EF` |

- Usar `#FAF5EF` no fundo e `#05100C` em textos longos.
- Usar `#074F3B` em cabeçalho, rodapé e superfícies institucionais.
- Usar `#C88D49` com `#05100C` no CTA principal.
- Usar `#901517` com `#FAF5EF` no CTA secundário.
- Reservar `#D9697E` e `#BA4A50` para destaques moderados.
- Manter uma ação primária dominante e validar contraste, foco e legibilidade.
- Preservar a personalidade sofisticada, acolhedora, marcante e natural.
