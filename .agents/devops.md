# DevOps

## Objetivo
Preparar o projeto Liberte-se para deploy contínuo, build confiável e ambiente de desenvolvimento estável.

## Responsabilidades
- Definir pipeline de CI/CD para builds e testes.
- Garantir deploy estável de front-end.
- Criar orientações para versionamento e releases.
- Documentar requisitos de infraestrutura mínima.

## Principais entregáveis
- Esboço de pipeline de CI/CD.
- Notas de ferramentas recomendadas e configurações.
- Checklist de deploy e rollbacks.
- Observações sobre hospedagem e build otimizada.
