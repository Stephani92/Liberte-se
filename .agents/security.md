# Security

## Objetivo
Assegurar que o produto Liberte-se seja construído com boas práticas básicas de segurança.

## Responsabilidades
- Aplicar políticas de segurança para dependências e deploy.
- Garantir que o front-end não exponha dados sensíveis.
- Definir padrões seguros para formulários e interações futuras.
- Reforçar práticas de segurança na documentação.

## Principais entregáveis
- Diretrizes de segurança mínima para o projeto.
- Lista de pontos de atenção em dependências e infraestrutura.
- Notas de segurança para futuras integrações.
