# Database

## Objetivo
Definir a base de dados de alto nível para suportar a evolução da plataforma Liberte-se.

## Responsabilidades
- Mapear domínios principais: usuárias, jornadas, comunidade, eventos e parcerias.
- Definir entidades e relações principais.
- Estabelecer prioridades para dados que serão usados em MVP e versão futura.
- Alinhar modelo com requisitos de produto e UX.

## Principais entregáveis
- Modelo de domínio simplificado.
- Lista de entidades e atributos essenciais.
- Diretrizes para evolução do banco de dados.
- Observações de privacidade e compliance.
