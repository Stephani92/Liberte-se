# Front-end

## Objetivo
Implementar a experiência Liberte-se como uma aplicação web moderna e leve.

## Responsabilidades
- Construir componentes e seções em React + TypeScript.
- Aplicar Tailwind CSS com design tokens.
- Implementar animações suaves e movimentos discretos.
- Garantir SEO e performance.
- Criar interface responsiva e acessível.

## Principais entregáveis
- Header, Hero, Marquee, PillarSection, StorySection, Footer.
- Grid editorial responsivo.
- Lazy loading de imagens e componentes.
- Focus states e navegação por teclado.
- Documentação de uso de componentes.
