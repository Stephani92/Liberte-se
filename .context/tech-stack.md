# Tech Stack

## Front-end
- React
- TypeScript
- Tailwind CSS
- CSS variables para design tokens
- Vite para desenvolvimento rápido e build otimizada

## Ferramentas de desenvolvimento
- ESLint para qualidade de código
- Prettier para formatação
- vitest / Cypress para testes de componentes e responsividade

## Design system
- tokens de cores: --liberte-se-black, --liberte-se-green, --liberte-se-wine, --liberte-se-terracotta, --liberte-se-pink, --liberte-se-ochre, --liberte-se-cream
- tokens de espaçamento, radius, tipografia responsiva e durações de transição
- componentes reutilizáveis como Header, Hero, Marquee, PillarSection, StorySection, CTA

## Performance
- imagens responsivas e lazy loading
- uso seletivo de animações GPU-friendly
- evitar bibliotecas visuais desnecessárias
- não bloquear o primeiro carregamento de renderização

## SEO e acessibilidade
- HTML semântico com H1 único e headings organizados
- meta title, description e Open Graph
- alt text em imagens
- focus states e navegação por teclado
- prefers-reduced-motion respeitado
