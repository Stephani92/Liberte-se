# Referência Visual

## Fonte de verdade
A referência visual do projeto é o próprio briefing do DOCUMENTO 02 LP, com apoio conceitual do site:
- https://libertese-html-showcase.lovable.app/

## Principais requisitos
- faixa de texto contínuo em movimento
- composição editorial
- ritmo de scroll
- grandes áreas visuais
- uso de imagens e transições sofisticadas
- narrativa vertical

## Regras de uso
- não copiar literalmente o site de referência
- interpretar a estrutura dentro da identidade do Liberte-se
- usar o briefing como guia principal para cores, tipografia e direções visuais
- preservar a originalidade e a sensação proprietária do produto
