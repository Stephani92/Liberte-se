# Diretrizes de UX

## Header
- Desktop:
  - logo LIBERTE-SE à esquerda.
  - menu com links: O Liberte-se, Experiências, Para marcas.
  - CTA no topo.
- Mobile:
  - logo.
  - menu hamburger minimalista.
  - CTA dentro do menu.
- Header transparente no início.
- Ao rolar: background #FAF5EF com leve blur e transição suave.

## Marquee / faixa contínua
- Elemento importante da experiência.
- Deve ter movimento linear e infinito.
- Não pode travar ou ter salto perceptível.
- Velocidade moderada.
- Hover desktop pode reduzir velocidade.
- Mobile mantém movimento reduzido.
- Deve respeitar prefers-reduced-motion.

## Hero
- Background off-white.
- Tipografia Bodoni protagonista.
- Imagem editorial ocupa grande parte da composição.
- Texto principal: "Você não precisa empreender sozinha."
- Subheadline curta.
- CTA claro.
- Pequeno detalhe em Parisienne.
- Composição deve parecer uma capa editorial digital.

## Scroll storytelling
- À medida que o usuário desce:
  - textos entram;
  - imagens mudam;
  - elementos se deslocam;
  - frases são reveladas.
- Usar animações discretas com opacity, translate, clip-path e scale muito sutil.

## Seção "Excesso de informação"
- Criar sensação de caos com palavras como:
  - CURSOS, REELS, GURUS, ESTRATÉGIAS, FERRAMENTAS, TENDÊNCIAS.
- Depois tudo desaparece e surge: "Você precisa de direção."
- Deve ser uma experiência memorável da página.

## Pilares
- Não usar cards tradicionais de SaaS.
- Criar composição editorial para as quatro áreas:
  - JORNADA
  - COMUNIDADE
  - EXPERIÊNCIAS
  - INTELIGÊNCIA
- Desktop pode ter parte da tela dedicada a cada área.
- No hover, mostrar imagem/textura e pequena animação.
- Mobile vira sequência vertical.

## "Imagine ter uma sócia"
- Seção de grande impacto.
- Headline grande: "Imagine ter uma sócia."
- Frases aparecem em posições diferentes durante o scroll.
- Final: "É isso que estamos construindo."
- Desktop pode usar sticky scroll.
- Mobile deve ser sequência natural.

## Futura plataforma
- Mockups de interface sem revelar tudo.
- Mostrar dashboard, trilha, recomendação, evento e comunidade.
- Algumas telas podem aparecer parcialmente fora da viewport.
- Usar blur ou crop para gerar curiosidade.

## Evento
- Fotografia em tela quase inteira.
- Texto sobreposto com poucas informações.
- Incluir Data, Local e CTA.
- Desktop pode ter parallax muito sutil.
- Mobile remove parallax pesado.

## Página de marcas
- Estética mais institucional, mas com personalidade.
- Hero com mensagem: "Sua marca ao lado das mulheres que movimentam a nova economia."
- Mostrar imagens de experiências.
- Sequência animada de:
  - VIAGENS ↓ EXPERIÊNCIAS ↓ COMUNIDADE ↓ PLATAFORMA ↓ ECOSSISTEMA

## Mobile
- Reduzir quantidade de elementos simultâneos.
- Aumentar legibilidade.
- Preservar Bodoni.
- Manter marquee.
- Reduzir animações.
- Transformar grids em stacks.
- Preservar imagens importantes.
- Manter CTAs acessíveis.
- Criar menu mobile próprio.

## Acessibilidade
- alt text em imagens.
- contraste adequado.
- focus states.
- navegação por teclado.
- HTML semântico.
- prefers-reduced-motion.
- animação não deve impedir acesso ao conteúdo.

## Copy
- Usar pouco texto.
- Priorizar headline forte, subheadline curta, visual e CTA.
- Se uma seção puder ser explicada por frase + imagem + interação, não criar parágrafo.
