## Estrutura do projeto
- `.agents/`: perfis de agentes e responsabilidades.
- `.context/`: regras do projeto, arquitetura, diretrizes visuais e checklist de revisão.
- `.skills/`: guias de habilidades e padrões.
- `docs/`: documentação de arquitetura e produto.
- `src/`: código-fonte da aplicação.

## Arquivos de briefing importantes

- `.context/typography.md`

## Como usar
1. Instalar dependências.
2. Rodar o ambiente de desenvolvimento.
3. Abrir em `localhost`.
